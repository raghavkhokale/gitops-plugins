# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

Full text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

To report a violation, email the maintainer at
**khokale.raghav@gmail.com**. Reports are reviewed privately;
reporters will not be identified to the rest of the community
without their consent.

Scope: all project spaces — issues, pull requests, discussions,
and any channel that represents the project publicly.
